# Embedded authored Rive asset

weather.riv is the existing original FLAME-authored Weather World scene from flame-resources/interactive/weather-world/rive/build/rive.riv. It was compiled with the official Rive CLI; the runtime does not generate artwork. It is bundled locally without resource retrieval. The accompanying RIVE-LICENSE.txt covers the Rive runtime. Community cat artwork remains in its existing administrator testing draft and is not distributed through this adapter.
