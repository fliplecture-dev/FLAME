## Import and mapping

The JSON companion records exact curriculum topic/subtopic IDs for FlipLecture and TN Stateboard where present. It is a coverage manifest, not a bulk-import workbook. Matching grade/topic mappings have been saved; each topic-wide link covers its current subtopics. Metadata suggestions include explain/demonstrate, English and the matching grade. Interactive files work with FLAME’s sandboxed HTML viewer. Open a file locally for author review, or upload/paste it into Resource Library and use Preview. No real student progress is recorded.
